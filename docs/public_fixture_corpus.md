# Public fixture corpus

This document records public data that can exercise SceneIO's 3D-CV I/O
contracts without importing non-commercial or ambiguously licensed bytes. The
machine authority is
[`tests/contracts/public_fixture_sources_v1.toml`](../tests/contracts/public_fixture_sources_v1.toml);
its contract test requires every built-in format to have exactly one primary
route.

## Current closure

As of 2026-08-03, all **74 built-in formats** have a fixture route:

- **13 direct formats** use an unchanged, content-hashed upstream artifact
  that SceneIO read locally;
- **61 derived formats** have a specified deterministic route from a
  CC0/CC-BY seed through a separately pinned independent writer/parser; and
- large real datasets and broader format profiles remain optional validation
  inputs, never normal-CI downloads.

"Derived" does not mean self-confirming. The source values come from a
licensed external scene, the writer/parser is named in the manifest, and the
result must pass the existing per-format oracle suite. Generated byte streams
are the practical answer when the format has no small, clearly licensed public
sample or when a public sample encodes semantics outside SceneIO's deliberately
bounded record.

No downloaded artifact is committed or packaged. Normal CI stays offline and
the base runtime remains NumPy-only.

The exact source IDs, derivation text, oracle IDs, and executable evidence paths
are in the TOML contract. A new format cannot enter the built-in registry
without extending this map.

## Deliberate exclusions and irreducible generated cases

- Official **EuRoC data** is not permissively redistributable. TUM-VI and
  Monado cover the real directory/pose/IMU family, but no permissive exact
  17-column public state file was found. The full state fixture therefore stays
  independently generated.
- Official **RTMV data** is CC-BY-NC-4.0. Its layout remains verified using
  independently authored JSON and permissive EXR content.
- NVIDIA **NCore/NuRec datasets** are CC-BY-4.0 but gated and very large. The
  pinned official writer-generated compact fixture remains the reliable normal
  route; hosted data is optional.
- The Middlebury **RubberWhale FLO** artifact decodes successfully, but its data
  terms are not within this corpus's approved license set. FLO closure uses
  independently projected CC0 data instead.
- Public OpenUSD, animated AVIF, LAZ, OME-TIFF, and other valid files can carry
  profiles SceneIO intentionally refuses. Such files are retained as negative
  vectors, not relabeled as positive fixtures and not used to weaken a record
  contract.

The remaining work is now implementation breadth rather than source hunting.
Semantic/instance/panoptic records, NPZ/Zarr/TIFF carriers, strict NCore
projections, and the hash-verified procedural Kubric result are present.
Kubric regeneration remains an explicit evidence operation rather than normal
CI or adapter work.
Dynamic USD, multi-grid VDB, multi-scan E57, and TIFF multi-series/pyramids
still need explicit public models and conversion contracts before the broader
samples can become positive round-trip cases.
The bounded implementation and verification order is defined in
[`remaining_3dcv_profile_checklist.md`](remaining_3dcv_profile_checklist.md).
That plan's FC0 machine contract freezes the remaining proposed names and
provider limits; FC1B's `euroc_dataset` route is now checked separately.

## Validation rule

For a direct artifact:

1. download only into an ignored cache;
2. check byte count and SHA-256 before opening it;
3. run `sceneio.inspect` and `sceneio.read` with an explicit format;
4. compare structure/content with the named independent implementation; and
5. retain a valid out-of-profile artifact as a refusal vector when applicable.

For a derived artifact, record the source digest, pinned oracle revision,
generation parameters, output digest, and both cross-read directions. The
normal test suite remains fully offline; hosted acquisition is an explicit
validation action, not an import-time or package dependency.
