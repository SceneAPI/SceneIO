# SceneIO 0.4.0

SceneIO 0.4.0 is the pre-1 representation-contract reset. It replaces parallel
loaded and neutral models with one canonical public type per concept while
keeping the complete format-I/O capability inventory intact.

## Public representation outcome

- All 90 public in-memory data representations have one canonical public path.
- The root `sceneio` namespace owns shared records and their construction
  vocabularies.
- `sceneio.data`, `sceneio.canonical`, and public `sceneio.io.<Type>` aliases
  are removed; there is no legacy compatibility layer.
- The generic catalog contains 131 public class identities and 26 built-in
  payload kinds, with no alias or adapter relations.

The principal merges are:

| Removed parallel concepts | Canonical 0.4 type |
|---|---|
| Native and neutral cameras | `sceneio.CameraIntrinsics` |
| Native, neutral, and COLMAP SIFT feature wrappers | `sceneio.FeatureSet` |
| Match storage and neutral correspondence graphs | `sceneio.CorrespondenceGraph` |
| Native and neutral depth maps | `sceneio.DepthMap` |
| Native and neutral posed-view sets | `sceneio.PosedViewSet` |
| Tracked and untracked point clouds | `sceneio.PointCloud` |
| Static mesh scenes and rich scene graphs | `sceneio.SceneGraph` |

## I/O compatibility

The consolidation does not remove a format or direction. SceneIO 0.4.0 keeps:

- 74 readable, 73 writable, and 74 inspectable built-in formats;
- 43 bounded selectors across 37 formats;
- 74 streaming-read and 71 streaming-write implementations.

glTF, GLB, USD, and USDZ now read and write `SceneGraph`. COLMAP database and
HLoc match routes expose `CorrespondenceGraph`. TUM, KITTI, and transforms JSON
use `PosedViewSet`. Existing file bytes and bounded format profiles remain
covered by the same independent-oracle and round-trip suites.

## Upgrade posture

This project is new and pre-1, so 0.4.0 intentionally does not provide aliases,
deprecation shims, or automatic legacy conversion. Import shared data types
from `sceneio` and call I/O operations from the root API.
