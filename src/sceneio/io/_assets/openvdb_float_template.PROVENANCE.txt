Purpose:
TinyVDB 0.9.0 can replace an existing grid but cannot create a new VDB file
from Python. SceneIO opens this upstream one-grid float fixture, replaces the
entire grid with caller-provided sparse coordinates and values, and saves the
result. No fixture voxels are retained in written files.
